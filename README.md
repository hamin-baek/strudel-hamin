## Overview

This repository contains music patterns created using [Strudel](https://strudel.tidalcycles.org/), a web-based live coding environment for algorithmic music composition. Each pattern explores different aspects of electronic music production through code-based composition techniques.

## Features

- Polyrhythmic pattern compositions
- Real-time synthesis control with sliders
- Multi-layered arrangements (synth, bass, drums)
- Audio effects processing (distortion, delays, filters)
- Stereo panning and spatial audio design

## Getting Started

### Prerequisites

- Web browser with audio capabilities
- Access to [Strudel web editor](https://strudel.tidalcycles.org/)

### Usage

1. Open the [Strudel web editor](https://strudel.tidalcycles.org/)
2. Copy and paste any pattern from this repository
3. Press `Ctrl+Enter` (or `Cmd+Enter` on Mac) to start playback
4. Use the interactive sliders to control volume and parameters
5. Modify the code live to experiment with variations

### Example Usage

```javascript
// Basic pattern structure
$synth: n('0 2 4 7').scale('C:major').s('triangle').gain(0.5)
```

## Pattern Collection

### REDRED_CORTIS.js

A multi-layered composition featuring:

- **Synth Lead**: Structured melodic patterns with supersaw synthesis
- **Bass Line**: Sub-bass frequencies with harmonic intervals
- **Drum Kit**: Classic kick and snare rhythm section
- **Effects**: Distortion, low-pass filtering, and stereo delay

**Key Features:**

- A minor scale progression
- Interactive gain controls via sliders
- Polyrhythmic structures with syncopated timing
- Stereo field positioning for spatial depth
